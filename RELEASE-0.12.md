# Echo-All 0.12 — Bibliothèque et lecteur affinés

- Navigation : seul l’onglet actif affiche son texte, avec une légère lueur et une pastille animée.
- Vidéos : grandes vignettes 16:9, durée, progression et section « Continuer à regarder ». Les vidéos presque terminées repartent du début. Les flux sans durée connue ne proposent pas de reprise ; une vignette personnalisée peut être choisie.
- Musique : onglets Titres, Artistes et Albums, pages dédiées, albums filtrables par artiste et lecture de la sélection dans sa propre file.
- Paroles : aperçu synchronisé directement dans le lecteur, ligne active surlignée, déplacement en touchant une ligne et accès à la vue complète. La synchronisation dépend de la disponibilité des paroles horodatées.
- Métadonnées : menu du morceau → Annuler la correction automatique, avec aperçu avant restauration. Les favoris et le classement sont conservés. La recherche automatique est ensuite bloquée pour ce morceau. Seules les corrections effectuées à partir de cette version disposent d’un historique annulable ; les anciennes valeurs de la 0.11 ne peuvent pas être reconstituées.

## Installation et essais sur téléphone
Installer Echo-All-0.12.apk par-dessus la version précédente sans désinstaller.
Le test physique est laissé à l’utilisateur, à sa demande. Vérifier :
1. Navigation : texte uniquement sur la page active, lueur lisible et absence de chevauchement avec le mini-lecteur.
2. Vidéo : lire une minute, quitter puis reprendre depuis « Continuer à regarder ».
3. Artiste / album : lancer une sélection et vérifier que la file ne contient que ses titres.
4. Paroles : vérifier la synchronisation audible, toucher une ligne, tester le décalage dans la vue complète.
5. Métadonnées : annuler une nouvelle correction automatique puis relancer le morceau et un scan ; vérifier les favoris et la restauration.

Validation PC : build release réussi ; 75 tests, 0 échec, 0 erreur ; signature vérifiée identique à la 0.11. Rendu et audio sur téléphone non vérifiés.
